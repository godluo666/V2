# 美术设计方案 ——「月汐町·晴日生活街」

> 本文是户外街区与公共室内的当前视觉、尺度和技术契约。角色造型、角色配色、
> 动画与交互能力保持不变；本轮只优化环境、动线、采光与空间感。

## 1. 核心感受

一句话：晴朗海边小町里的短生活街，明亮、温暖、近距离有事可做，进屋后能自然
坐下聊天，又不会被家具和人群挤满。

- 默认主画面是清透白天：高亮蓝天、暖白太阳、柔和清晰的阴影。
- 黄昏、夜晚、阴雨继续作为动态状态存在，但不再定义整个世界的基础色。
- 建筑使用暖白、浅米、淡木色与低饱和蓝绿；鲜艳色只用于店招、花植和引导。
- 角色保持原样，环境提高明度后仍以描边、轮廓光和颜色对比保证可读性。

## 2. 尺度与动线

- 可玩边界：`96m × 84m`（x = -48..48，z = -42..42）。
- 四条道路臂最长 `38m`，中央路口 `16m × 16m`，道路宽 `10m`。
- 出生点位于 `28m × 12m` 的站前口袋广场，不使用大面积空铺装。
- 七个既有场馆全部保留，并集中在一分钟内可达的主街环上。
- 东西各保留一条短生活巷；远景楼只负责天际线，不扩大实际步行范围。
- 小型天桥桥面高 `4.2m`，四条坡道完全收在北街以内。

唯一坐标源是 `shared/src/cityplan.ts`；服务端碰撞、客户端渲染和浏览器路径不得
另写一套地图坐标。

## 3. 户外视觉

### 光照

- 晴日中段太阳强度约 `2.05–2.35`，半球光约 `0.86–0.96`。
- 晴日天空由明亮蓝顶过渡到暖白地平线，雾只用于柔化短街外的剪影楼。
- 白天路灯关闭，黄昏、夜晚和雨天按原有日夜系统自动点亮。

### 材质与构图

- 路面使用偏暖浅灰蓝，人行道使用浅砂岩色，避免大块黑灰占据画面。
- 临街建筑保持赛璐璐分层和轮廓线，增加暖墙、浅木与玻璃反光的比例。
- 道具以 2–4 件为一个生活事件组，沿边布置；出生通道、门口和斑马线保持净空。
- 18 栋剪影楼布置在约 `62–108m` 的视觉圈，仅构成近景天际线，不产生碰撞。

## 4. 室内空间

公共室内以“宽松而不空”为准：家具靠墙或成组布置，中部留出主通道，窗边、
柜台和后区形成可停留的小角落。

| 空间 | 当前尺寸 | 空间策略 |
| --- | ---: | --- |
| 咖啡馆 | 18m × 14m | 桌组拉开，书架与柜台靠边，暖窗光 |
| 电影院 | 30m × 24m | 50 座、三段座区、双宽过道、后排休息区 |
| 游戏厅 | 16m × 14m | 机台沿边，中央回转区保持通畅 |
| 百货店 | 16m × 14m | 货架分区但不形成狭窄迷宫 |
| 团子塔大厅 | 18m × 14m | 会客家具分组，入口到电梯保持直达 |
| 电竞馆 | 20m × 15m | 8 个宽松机位、大中央过道、后区沙发 |
| 雀庄 | 18m × 14m | 两张日麻桌、一张象棋桌，桌组互不干扰 |
| 个人房间 | 14m × 12m | 窗光、暖灯、家具编辑余量更大 |

室内使用暖白环境光、窗边柔光和局部暖色点光。影院可以在播放时压暗，但走道、
台阶与出入口始终可读。

## 5. 性能与依赖

- 继续使用程序化几何、实例化道具、质量分级、雾内裁剪与分帧构建。
- 不从 CDN 运行代码，不在工作区外安装项目依赖。
- 云端浏览器测试把 Playwright 包和 Chromium 都安装到 GitHub 工作区内。
- 仓库内不提交 `node_modules`、浏览器二进制、数据库或测试截图。

## 6. 验收标准

1. 角色源码与造型未改动。
2. 可玩街区宽不超过 100m、深不超过 90m，单条道路臂不超过 40m。
3. 七个场馆门可达，出生点、门前站位、短巷与天桥路径不被碰撞体卡住。
4. 晴日中段太阳强度不低于 2.2、半球光不低于 0.9，天空与地平线保持明亮。
5. 电竞馆保留 8 个机位，雀庄保留完整桌组；影院减少到 50 座并保留宽过道。
6. 类型检查、共享/服务器/客户端单元测试、生产构建和四条浏览器冒烟链路全部
   只在云端 CI 执行。
