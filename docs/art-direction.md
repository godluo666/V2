# 美术设计方案 ——「月汐町·一番街」

> 产品范围、联机同步和后续扩展规则见
> [CURRENT_SCENE_REQUIREMENTS.md](CURRENT_SCENE_REQUIREMENTS.md)。本文件只定义当前版本的
> 视觉、尺度和空间实现。

## 1. 核心感受

一条晴朗、紧凑、绚烂的漫画都市生活街。参考 P5 涩谷街头的高对比构图、斜向节奏和
招牌密度，但全部使用《月汐町》的原创建筑、色板、文字、图形和程序化几何。

- 天空明亮通透，默认是带暖色太阳的晴日。
- 深墨色路面负责衬托，红、青、黄集中在招牌、雨棚、海报和路面图形。
- 暖白住宅立面与阳台围住街道，近景电线、自行车、花槽和店招增加层次。
- 不改动角色模型、角色配色系统、动画或控制表现。
- 绚烂不等于过曝：角色、门、斑马线和交互提示始终保持清晰轮廓。

## 2. 户外尺度与动线

- 可玩边界：`58m × 46m`（x = -29..29，z = -23..23）。
- 路网：`54m × 7.2m` 东西主街与 `42m × 7.2m` 南北短街组成紧凑十字；中央图形区
  只有 `10m × 7.2m`，不扩成广场。
- 八段约 `3.5m` 宽的短步道包住四角，四组斑马线完成过街；道路之外立即是街具、店面
  或楼体，不设置无内容退界。
- 出生点位于南侧斑马线，默认镜头沿短街直看十字路口、街旗和两侧高层招牌，沿共享路线
  步行数秒可达三个入口；
  不使用车站、天桥或长支路。
- 北侧排列电影院与高层媒体楼，西侧是团子轰趴馆，南侧是电竞观战馆和住宅高楼。
- 近景楼高约 `22–42m`；18 栋 `28–64m` 远景剪影只构成天际线，不产生碰撞或扩大地图。

唯一坐标源是 `shared/src/cityplan.ts`。服务端碰撞、客户端渲染与云端浏览器路径必须
使用同一份数据。

## 3. 户外视觉语言

### 光照

- 晴日蓝天向暖白地平线过渡，太阳投出清晰但不生硬的阴影。
- 暖色窗光只作小面积点缀；白天不让路灯大面积发光。
- Bloom 只覆盖高亮招牌与灯芯，画面主体保持锐利。
- 使用轻微增艳和克制暗角，让视觉有漫画冲击力但不压暗边缘。

### 建筑

- 一层场馆使用通透橱窗、宽门棚、主招牌和侧挂灯箱。
- 上层住宅使用阳台、外廊、空调、晾衣杆、暖窗和屋顶小体块。
- 四个街角的立面贴住步道外缘，楼间只用接缝和窄巷制造节奏，不形成可继续走远的空地。
- 大型贴墙屏、横向店招和垂直刀牌从共享建筑数据生成；高处信息密、低处入口清楚。
- 建筑墙面以暖白、浅木、低饱和粉灰和蓝绿为主，深墨只用于描边与结构。

### 街面

- 街心使用原创红/青/黄不对称楔形、深墨斜切和暖白速度线。
- 图形需带轻微磨损，使其属于路面而非悬浮贴纸。
- 自行车、长椅、花槽、海报、电话、售货机和电线杆靠边成组放置。
- 三个入口前至少保留约 `3m` 可读净空。

## 4. 场馆视觉与空间

| 空间 | 尺寸 | 视觉与空间策略 |
| --- | ---: | --- |
| 星汐电影院 | 30m × 24m | 深莓红软装、暖色通道灯、巨幕、5 排 50 座、三段座区、实体地毯台阶 |
| 镜界电竞观战馆 | 20m × 15m | 蓝青联赛大屏和灯带配暖木前台；8 个机位靠边，中部留观战通道 |
| 团子轰趴馆 | 24m × 18m | 奶油墙、暖木地面、软毯沙发、茶水台、象棋、飞行棋、社团墙和小舞台 |

### 电影院落地规则

- 第 1 排地面高度为 `0`，随后每排增加 `0.24m`。
- 台阶顶面、座椅 prefab 原点、共享 `heightZone` 和 Seat Snap Point 使用同一个 `lift`。
- 椅子最低实体几何必须恰好接触其原点平面，不能留下视觉缝隙。

### 团子轰趴馆

- 沙发与软毯组成可围坐的主客厅，中部和入口保持通行。
- 象棋桌是已有的服务端权威玩法。
- 飞行棋桌有四个彩色阵营、实体棋子和四方座位；当前只作为可围坐陈设。
- 小舞台、点歌机、茶水台、书架、白板、奖杯照片墙和绿植构成社团活动室叙事。

## 5. 性能与资源

- 优先使用程序化几何、合并网格、实例化道具和 CanvasTexture。
- 不从 CDN 加载运行代码；新增资源与依赖必须位于本仓库。
- 保留画质分级、雾裁剪、分帧构建和移动端低画质路径。
- 本地不运行测试或构建；类型、单元、生产构建和浏览器验收全部交给 GitHub Actions。

## 6. 美术验收

1. 角色源文件与外观系统未改变。
2. 户外是边界未扩大的紧凑十字街，且只有三个可进入场馆。
3. 四个街角从路缘起即由高层立面围合，不出现旧车站、天桥、大广场、长空地或旧场馆入口。
4. 画面晴朗绚烂，入口、角色和道路仍清晰可读。
5. 电影院 50 把椅子全部接触对应地面或台阶。
6. 轰趴馆有象棋、飞行棋、沙发软毯和社团活动室陈设，且主通道不拥挤。
7. 云端 Chromium 完成街区、轰趴馆、电影院和双人同步旅程。
